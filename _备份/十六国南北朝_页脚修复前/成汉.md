# 成汉

## 📌 基本信息

- **政权名称**：成汉（初称「成」，338年[[李寿]]改国号为「汉」）
- **存在时间**：304—347年
- **建立者**：[[李雄]]
- **都城**：成都
- **核心地区**：巴蜀
- **所属历史阶段**：五胡十六国（**与[[前赵|汉赵]]同为最早建国的政权之一**）

## 👑 统治者

- [[李雄]]（开国）
- [[李班]]
- [[李期]]
- [[李寿]]（改国号为汉）
- [[李势]]（末主）

## 🏛️ 政治制度

**由流民军演变而来的政权，前期「宽和政简」而后期内乱 —— 十六国中最早建国的政权之一**：

- **由流民军演变而来**：**[[李特]]以「**赈施穷乏**」得六郡流民之心**；**[[李雄]] 304 年据成都称王** —— **其权力基础为「**流民与巴氐部众**」而非世袭**（见 [[李特]]、[[李雄]] 条）
  - **此与十六国其他开国者有根本区别** —— **李氏三代的领导权传承为「**[[李特]] → [[李流]] → [[李雄]]**」**（见 [[李特]]、[[李流]] 条）
- **「**宽和政简**」（前期）**：**[[李雄]]「**简刑约法，与民休息**」** —— **使蜀中成为乱世中的富庶安定之地**（见 [[李雄]] 条）
  - **兼用汉人士族与蜀中势力**：**以**范长生**（天师道领袖）为所倚重**（见 [[李雄]] 条）
- **【制度的失败】**：
  - **立嗣失当**：**[[李雄]]立兄子[[李班]]而未立己子** —— **此为其身后争立的根源**（见 [[李雄]]、[[李班]] 条）
  - **宗室内乱（334—347年）**：**[[李班]]（数月被杀）→ [[李期]]（弑君骄虐）→ [[李寿]]（篡位·由俭入奢）→ [[李势]]（骄淫亡国）** —— **十三年而四易其主**（见 [[李班]]、[[李期]]、[[李寿]]、[[李势]] 条）
- **改国号为「汉」（338年）**：**[[李寿]]废[[李期]]自立，**改国号由「成」为「汉」** —— **「**成汉**」之名由此而来**；**且借汉室之名以自固**（**与[[刘渊]]的汉赵同策**，见 [[李寿]]、[[前赵]] 条）
- **【历史意义】**：**成汉历六主四十三年（304—347）** —— **「**是十六国中最早的政权之一，也是最早灭亡的主要政权**」（见 [[李雄]] 条）

## ⚔️ 军事体系

**由流民军起家，据巴蜀天险；终为东晋桓温所灭**：

- **流民武装为核心**：**六郡流民十余万 + 巴氐部众**（见 [[李特]] 条）
- **【关键战役】**：
  - **301—303年**：**[[李特]]、[[李流]]与西晋益州刺史罗尚作战**（**303 年[[李特]]战死、[[李流]]同年卒**，见 [[李特]]、[[李流]] 条）
  - **304年**：**[[李雄]]攻下成都，自称成都王，[[成汉]]建立**
  - **306年**：**[[李雄]]称帝**
  - **347年**：**东晋桓温伐蜀，[[李势]]出降，成汉亡**
- **【军事的强盛】**：**[[李雄]]时据巴蜀天险** —— **三十年之治使蜀中成为乱世中的安定之地**（见 [[李雄]] 条）
- **【军事的衰败】**：**[[李雄]]卒后（334年）宗室内乱** —— **军事力量在内耗中削弱**；**347 年桓温来攻，**[[李势]]出降**（见 [[李势]] 条）
- **【军事的特点】**：**成汉的军力据巴蜀天险** —— **「**蜀中天险与富庶，为成汉三十年安定的基础**」（见 [[李雄]] 条）
- **【历史意义】**：**桓温灭成汉（347年）是东晋立国以来最重要的一次开疆**（见 [[李势]] 条）

## 💰 财政与经济

**据巴蜀，为十六国中少见据有蜀地者；前期富庶而后期内乱耗竭**：

- **据巴蜀**：**蜀中自秦汉以来即为富庶之区** —— **「据巴蜀，为十六国中少见据有蜀地者」**（见 `📌基本信息`）
- **【前期的经济】**：**[[李雄]]「**与民休息**」使经济得以恢复** —— **「**成汉三十年的安定，正是巴蜀经济优势的体现**」（见 [[李雄]] 条）
- **【后期的耗竭】**：
  - **[[李期]]「**骄虐，诛杀无度**」**（见 [[李期]] 条）
  - **[[李寿]]「**大兴宫室、赋役繁重**」** —— **[[李雄]]三十年之治积累的国力，在本期被大量消耗**（见 [[李寿]] 条）
  - **[[李势]]时经济已濒于崩溃**（见 [[李势]] 条）
- **【经济的结局】**：**347 年成汉灭亡，蜀中入东晋版图**（见 [[李势]] 条）
- **【经济的特点】**：**成汉的经济基础为巴蜀的富庶** —— **「**[[李雄]]三十年之治的成果，在其身后十三年内消耗殆尽**」（见 [[李班]] 条）

## 🗺️ 疆域变化

**据巴蜀（今四川一带），为十六国中少见据有蜀地者**：

- **301—303年**：**[[李特]]、[[李流]]的流民军活动于蜀中**（见 [[李特]] 条）
- **304年**：**[[李雄]]攻下成都，自称成都王** —— **据**巴蜀**
- **【疆域的范围】**：**据今四川一带（成都为中心）**
  - **北与[[前赵|汉赵]]、[[后赵]]以秦岭为界**
  - **东与东晋以三峡为界**
- **【疆域的稳定】**：**304—334 年（[[李雄]]时期）疆域基本稳定** —— **蜀中天险使其少受外患**
- **【后期】**：**334—347 年宗室内乱，**疆域未大变**
- **347年**：**为东晋桓温所灭** —— **蜀中入东晋版图**
- **【其后蜀中的归属】**：**东晋 → [[胡夏]]（413年前后）→ 东晋（刘裕）→ [[胡夏]] → [[北魏]]**（见 [[李势]] 条）
- **【疆域的特点】**：**成汉据巴蜀，**天险使其在乱世中得以自存** —— **然「**据天险者亦易自守而忘进取**」；**其四十三年（304—347）的存在，**主要赖蜀中的地理与[[李雄]]时期的安定**

## 🌍 对外关系

- **与西晋**：**[[李特]]、[[李流]]起义反抗西晋强令流民还乡的政策**（**益州刺史罗尚为主要对手**，见 [[李特]] 条）
- **与东晋**：**西晋于 316 年亡**；**东晋建立后与成汉以三峡为界对峙** —— **347 年桓温灭成汉**（见 [[李势]] 条）
- **与[[前赵|汉赵]]**：**同年（304年）建国的两个政权** —— **成汉据蜀，汉赵据中原**（见 [[前赵]]、[[李雄]] 条）
- **与[[后赵]]**：**[[石勒]]统一北方大部后，成汉与之相隔**（见 [[后赵]] 条）
- **与[[前凉]]**：**并立的割据政权**（**[[张骏]]曾向南联络成汉（[[李雄]]）** —— **共抗中原政权**，见 [[张骏]] 条）
- **与蜀中天师道**：**[[李雄]]倚重**范长生**（天师道领袖）**（见 [[李雄]] 条）
- **与西域**：**相隔甚远**（**然蜀中为南方丝路的起点之一**，<!-- TODO: 待补 核对 -->）
- **【外交特点】**：**成汉的对外关系以「**据蜀自守**」为核心** —— **其与中原政权（[[前赵]]、[[后赵]]）以秦岭为界**；**与东晋以三峡为界** —— **天险使其少受外患，**然亦使其未能扩张**

## 📅 关键事件

- **304年**：**[[李雄]]称成都王，成汉建立**
- **306年**：**[[李雄]]称帝**
- **334年**：**[[李雄]]卒；[[李班]]继位，**旋为[[李期]]所杀**（见 [[李雄]]、[[李班]] 条）
- **338年**：**[[李寿]]废[[李期]]自立，改国号为「汉」**（见 [[李寿]] 条）
- **343年**：**[[李寿]]卒；[[李势]]继位**（见 [[李势]] 条）
- **347年**：**[[李势]]降于东晋桓温，成汉灭亡**

## 📉 建立、发展与灭亡

**四十三年（304—347）：十六国中最早的政权之一，亦最早灭亡的主要政权**：

- **① 奠基与建国（301—334年）**：
  - **301—303 年[[李特]]、[[李流]]率流民军与西晋作战**（**[[李特]]战死、[[李流]]同年卒**，见 [[李特]]、[[李流]] 条）
  - **304 年[[李雄]]攻下成都，自称成都王；306 年称帝** —— **成汉建立（与[[前赵|汉赵]]同年，为十六国中最早）**
  - **「**简刑约法，与民休息**」** —— **三十年之治使蜀中安定富庶**（见 [[李雄]] 条）
- **② 内乱（334—347年）**：
  - **[[李雄]]卒（334年）；**立嗣失当（立兄子[[李班]]而未立己子）** —— **此为其身后争立的根源**（见 [[李雄]]、[[李班]] 条）
  - **[[李班]]（数月被杀）→ [[李期]]（弑君骄虐）→ [[李寿]]（篡位·改国号为汉·由俭入奢）→ [[李势]]（骄淫亡国）** —— **十三年而四易其主**
- **③ 灭亡（347年）**：**东晋桓温伐蜀，[[李势]]出降，成汉亡**
- **【灭亡的根本原因】**：**[[李雄]]「**立侄不立子**」的失策** + **诸主的相继失政**（**[[李期]]弑君骄虐、[[李寿]]由俭入奢、[[李势]]骄淫**）—— **[[李雄]]三十年之治的成果在十三年内消耗殆尽**（见 [[李班]] 条）
- **【历史意义】**：
  - **成汉是十六国中最早建立（304年）的政权，也是最早灭亡的主要政权（347年）**
  - **桓温灭成汉是东晋立国以来最重要的一次开疆**（见 [[李势]] 条）

## 🔗 与其他政权关系

- **前身**：**巴氐李氏流民军**（**[[李特]]、[[李流]]**）
- **继承者**：**东晋**（347年桓温灭成汉）
- **盟友**：**[[前凉]]（[[张骏]]曾与之联络以抗中原）**（见 [[张骏]] 条）
- **主要对手**：**西晋**、东晋
- **同年建国者**：**[[前赵|汉赵]]（304年）**
- **所辖之地**：**巴蜀（今四川一带）**
- **后世传承**：**成汉亡后蜀中入东晋**；**其后为[[胡夏]]所有**（413年前后）**，**再归东晋、[[胡夏]]，**终入[[北魏]]**

## ⚖️ 历史评价

**十六国中最早建立（304年）的政权，也是最早灭亡的主要政权（347年）；由流民军而立国，因立嗣失当与相继失政而亡**。

**其最可贵之处是「**宽和政简**」**：**[[李雄]]「**简刑约法，与民休息**」** —— **在中原战乱频仍的十六国时期，**巴蜀因[[李雄]]三十年的宽和政策而保持了安定与富庶**（见 [[李雄]] 条）。

**其建国路径最为特殊**：**由六郡流民十余万入蜀的流民军演变而来** —— **[[李特]]以「**赈施穷乏**」得众心**；**李氏三代的领导权传承为「**[[李特]] → [[李流]] → [[李雄]]**」**（见 [[李特]]、[[李流]]、[[李雄]] 条）—— **此与十六国其他开国者有根本区别**。

**其败亡则在于「**立嗣失当**」**：**[[李雄]]立兄子[[李班]]而未立己子** —— **其卒后立即内乱**（**[[李班]]被杀、[[李期]]自立、[[李寿]]篡位**）；**「**[[李雄]]三十年之治的成果，在其身后十三年内消耗殆尽**」（见 [[李班]] 条）。

## 🔀 争议与不同观点

> [!quote] ⚖️ 争议说明
> - **争议点一：立国时间**——**以[[李雄]] 304 年称王为准**；**然[[李特]]（301年起义）、[[李流]]阶段是否计入，说法不一**（**《晋书》以[[李特]]载记冠于成汉诸主之首**，见 [[李特]]、[[李雄]] 条）。**本库采用「**[[李特]]为奠基者、[[李雄]]为开国**」的处理**
> - **争议点二：国号「成」与「汉」**——**[[李雄]]初国号为「成」，338 年[[李寿]]改为「汉」**，**故史称「**成汉**」**。**一方视为同一政权，一分为二处理**（见 [[李寿]] 条）
> - **争议点三：[[李雄]]「**立侄不立子**」的评价**——**一方视为报答兄恩**（**其兄李荡早死**）；**一方视为失策**（见 [[李班]] 条）
> - **争议点四：[[李特]]起义的性质**——**一方视为流民反抗苛政的正义之举**；**一方（西晋官方叙述）视为叛乱**。**现代研究多强调其流民生存诉求**（见 [[李特]] 条）
> - **争议点五：范长生的作用**——**蜀中天师道领袖范长生对[[李雄]]建国的助力，各书记载详略不一**（见 [[李雄]] 条）
> - **来源**：《晋书·李特载记》《李流载记》《李雄载记》《李班载记》《李期载记》《李寿载记》《李势载记》（卷一二〇、一二一）**《华阳国志》**（**记载成汉最详的同期史料**）《资治通鉴》卷八四—九七
