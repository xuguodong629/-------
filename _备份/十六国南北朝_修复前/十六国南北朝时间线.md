# 十六国南北朝时间线（304—589）

> 北方多政权并立（十六国、北朝），南方相继更替（东晋、南朝），民族大融合的关键期。

## 🏛️ 主要政权

- 十六国：[[前赵|汉赵]]、[[后赵]]、[[前燕]]、前秦、[[后秦]]、[[后燕]]、[[南燕]]、[[北燕]]、夏、[[成汉]]、[[前凉]]等
- 北朝：北魏 → [[东魏]]／[[西魏]] → [[北齐]]／[[北周]]
- 南朝：宋 → 齐 → 梁 → 陈
