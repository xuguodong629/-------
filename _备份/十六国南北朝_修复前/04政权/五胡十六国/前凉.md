# 前凉

## 📌 基本信息

- **政权名称**：前凉
- **存在时间**：301—376年
- **建立者**：[[张轨]]（奠基，301年出任凉州刺史）／[[张寔]]（继掌，实为立国之始）
- **都城**：姑臧（今甘肃武威）
- **核心地区**：河西走廊
- **所属历史阶段**：五胡十六国（五凉之一）

## 👑 统治者

- [[张轨]]（奠基）
- [[张寔]]
- [[张骏]]（鼎盛）
- [[张重华]]
- [[张天锡]]（末主）

## 🏛️ 政治制度

**以晋臣自居的世袭政权 —— 十六国中最特殊的政治形态**：

- **「**晋臣**」的身份**：**[[张轨]]以**西晋凉州刺史**起家**；**子孙世袭其职，**然始终「**奉晋正朔**」**
  - **[[张轨]]、[[张寔]]奉西晋／东晋正朔**（**[[张寔]]于 316 年西晋亡后改奉东晋**，见 [[张寔]] 条）
  - **[[张骏]]「**假凉王**」** —— **名义上仍奉晋正朔，然已实际称王**（见 [[张骏]] 条）
  - **故前凉在形式上不是「自立」的政权，而是「世袭的晋臣」**
- **【与十六国其他政权的根本区别】**：
  - **[[刘渊]]、[[石勒]]等**：**自立称帝、改元建号**（见 [[前赵]]、[[后赵]] 条）
  - **前凉**：**始终以晋臣自居**，**仅称「**凉州刺史**」「**西平公**」「**假凉王**」** —— **不改元、不称帝**（**唯张祚一度称凉王**，见 [[张重华]] 条）
- **【制度的演变】**：**[[张轨]]（凉州刺史）→ [[张寔]]（世袭确立）→ [[张骏]]（假凉王）→ [[张重华]]（盛极而衰）→ [[张天锡]]（末主）**
  - **「**其兴也以保境安民，其亡也以宗室内争**」** —— **[[张重华]]卒后（353年）前凉陷入内乱，**君主更替频繁**（**张曜灵、张祚、张玄靓、[[张天锡]]**），**终为[[前秦]]所灭（376年）**（见 [[张重华]]、[[张天锡]] 条）
- **【历史意义】**：**前凉是十六国中唯一始终奉晋正朔的政权** —— **这使其在文化正统上占有优势**（见 `⚖️历史评价`）

## ⚔️ 军事体系

**以保境安民为主，兼有对西域的经略；终为前秦所灭**：

- **以凉州军政为基础**：**[[张轨]]「**保据河西**」，**平定凉州内乱、击退鲜卑羌人**（见 [[张轨]] 条）
- **【关键战役】**：
  - **301—310年**：**[[张轨]]平凉州内乱、击退外患**
  - **311年前后**：**[[张轨]]遣军入援洛阳、长安**（**助西晋对抗[[前赵|汉赵]]**，见 [[张轨]] 条）
  - **330年前**：**[[张骏]]击退[[前赵]][[刘曜]]的进攻**（见 [[张骏]] 条）
  - **347—349年**：**[[张重华]]以谢艾为主将，大破[[后赵]][[石虎]]军** —— **前凉对外的最后一次大胜**（见 [[张重华]] 条）
  - **376年**：**[[前秦]][[苻坚]]灭前凉**（见 [[张天锡]] 条）
- **【军事的特点】**：**前凉以「**保境安民**」为军事方针** —— **不主动扩张，**亦不参与中原的争霸**（见 [[张轨]] 条）
  - **然「**保境**」需有实力**：**[[张重华]]以谢艾破[[后赵]]即其例**（见 [[张重华]] 条）
- **【军事的衰落】**：**[[张重华]]卒后（353年）宗室内争** —— **军事力量在内耗中削弱**；**376 年[[前秦]]来攻，**[[张天锡]]未作坚决抵抗即降**（见 [[张天锡]] 条）

## 💰 财政与经济

**河西走廊商贸与屯田 —— 十六国中经济最稳定的地区之一**：

- **河西走廊的丝路商贸**：**河西为丝绸之路东段要道** —— **[[张轨]]保境后丝路东段得以通行**（见 [[张轨]] 条）
  - **[[张骏]]经营西域后，「**西至葱岭**」，**中西商贸畅通**（见 [[张骏]] 条）
- **屯田与劝课农桑**：**[[张轨]]「**劝课农桑**」** —— **奠定河西的经济基础**（见 [[张轨]] 条）
- **安置中原流民**：**永嘉之乱后「**避难来者日月相继**」** —— **[[张轨]]分武威置武兴郡以处之**（见 [[张轨]] 条）
  - **流民带来人力与财力** —— **为前凉近百年的存在奠定经济基础**
- **【经济的稳定】**：**前凉是十六国中少有的长期安定之区** —— **「**境内晏然**」**（见 [[张轨]] 条）；**[[张骏]]时「**士马强盛**」**
- **【经济的衰退】**：**[[张重华]]晚年怠政、宗室相争** —— **经济逐渐耗损**；**376 年为[[前秦]]所灭**（见 [[张重华]] 条）
- **【经济的特点】**：**前凉的经济基础为「**丝路商贸 + 屯田 + 流民**」** —— **此三者使其在乱世中维持了近百年的安定**

## 🗺️ 疆域变化

**张骏时极盛，控有西域部分；376年为前秦所灭**：

- **301年**：**[[张轨]]出任凉州刺史** —— **据河西**
- **【疆域的扩张】**：
  - **[[张寔]]时**：**安置流民，**据河西走廊**
  - **[[张骏]]时**：**「**尽有陇西之地，士马强盛**」**；**东扩陇西、西营西域** —— **「**西至葱岭，东至秦陇**」（见 [[张骏]] 条）
- **【疆域最盛时】**：**[[张骏]]时期（324—346年）** —— **据**河西走廊、陇西部分，并控有西域部分**（见 [[张骏]] 条）
- **【疆域的收缩】**：
  - **[[张重华]]时**：**以谢艾破[[后赵]]，**然已无力扩张**（见 [[张重华]] 条）
  - **[[张重华]]卒后（353年）**：**宗室内争，**国势急转直下**
- **376年**：**为[[前秦]]所灭** —— **其地入[[前秦]]**（见 [[张天锡]] 条）
- **【疆域的特点】**：**前凉据河西走廊，**为十六国中地理位置最西的政权之一** —— **其「**河西 + 西域部分**」的格局使其在中原战乱中得以自存**

## 🌍 对外关系

- **与西晋／东晋**：**名义上长期奉晋正朔** —— **[[张轨]]屡派兵勤王**；**[[张寔]]于 316 年西晋亡后改奉东晋**（见 [[张轨]]、[[张寔]] 条）
  - **这是前凉对外关系的核心** —— **与十六国其他政权的「**自立**」形成根本区别**
- **与[[前赵]]（汉赵）**：**[[张轨]]拒其招诱**；**[[张骏]]击退[[刘曜]]的进攻**（见 [[张轨]]、[[张骏]] 条）
- **与[[后赵]]**：**[[张骏]]向后赵[[石勒]]称藩**（**两面外交**）—— **347—349 年[[张重华]]以谢艾大破[[石虎]]军**（见 [[张骏]]、[[张重华]] 条）
- **与[[成汉]]**：**[[张骏]]向南联络成汉（[[李雄]]）** —— **共抗中原政权**（见 [[张骏]] 条）
- **与[[前秦]]**：**376 年[[苻坚]]灭前凉**（见 [[张天锡]] 条）
- **与西域诸国**：**[[张骏]]「**西至葱岭**」，**通使大宛、于阗等** —— **前凉在西域的影响力达到顶峰**（见 [[张骏]] 条）
- **与[[成汉]]、[[前赵]]、[[后赵]]**：**并立的政权**
- **【外交特点】**：**前凉的外交以「**奉晋正朔 + 两面称藩**」为特点** —— **在小国与大国的夹缝中求存**（见 [[张骏]] 条）

## 📅 关键事件

- **301年**：**[[张轨]]出任凉州刺史，前凉奠基**
- **311年前后**：**永嘉之乱，中原士人大量西迁投依[[张轨]]**
- **314年**：**[[张轨]]卒；[[张寔]]继掌凉州**
- **316年**：**西晋亡；[[张寔]]改奉东晋正朔**
- **320年**：**[[张寔]]为部下所杀；弟张茂继掌**
- **324年**：**张茂卒；[[张骏]]继掌**（见 [[张骏]] 条）
- **345年**：**[[张骏]]自称「**假凉王**」**
- **346年**：**[[张骏]]卒；[[张重华]]继位**（见 [[张重华]] 条）
- **347—349年**：**[[张重华]]以谢艾为主将，大破[[后赵]]军**
- **353年**：**[[张重华]]卒；此后宗室内争，君主更替频繁**（**张曜灵 → 张祚 → 张玄靓 → [[张天锡]]**）
- **363年**：**[[张天锡]]废杀张玄靓自立**
- **376年**：**为[[前秦]][[苻坚]]所灭**

## 📉 建立、发展与灭亡

**七十五年（301—376）：十六国中最安定、最持久的政权之一**：

- **① 奠基与世袭（301—324年）**：
  - **301 年[[张轨]]自请刺凉，**保据河西**；**平内乱、退外患，**「**境内晏然**」（见 [[张轨]] 条）
  - **311 年永嘉之乱后，**中原士人大量西迁投依**（**「**避难来者日月相继**」**）
  - **314 年[[张轨]]卒；[[张寔]]继掌** —— **张氏世袭确立**；**316 年西晋亡后改奉东晋**（见 [[张寔]] 条）
- **② 鼎盛（324—353年）**：
  - **[[张骏]]时「**尽有陇西之地，士马强盛**」**；**东扩陇西、西营西域** —— **「**西至葱岭，东至秦陇**」（见 [[张骏]] 条）
  - **[[张重华]]以谢艾大破[[后赵]][[石虎]]军** —— **前凉对外的最后一次大胜**（见 [[张重华]] 条）
- **③ 内乱与灭亡（353—376年）**：
  - **[[张重华]]卒后（353年）宗室内争** —— **张曜灵、张祚、张玄靓、[[张天锡]]四主更替**
  - **[[张天锡]]「**荒于酒色**」；**376 年[[苻坚]]来攻，**降秦**（见 [[张天锡]] 条）
- **【灭亡的根本原因】**：**宗室内争** —— **[[张重华]]之死是前凉由盛转衰的转折点**；**353—376 年的二十三年内，**君主更替频繁，国势急转直下**（见 [[张重华]] 条）
- **【历史意义】**：
  - **前凉是十六国中少数**始终奉晋正朔**的政权** —— **其「**保境安民**」使河西成为乱世中的安定与文化保存之地**（见 `⚖️历史评价`）
  - **其保存的中原学术，后经[[北魏]]东传，**反哺北朝的礼乐制度**（**陈寅恪论隋唐制度渊源，特别重视河西一脉**）

## 🔗 与其他政权关系

- **前身**：**西晋凉州**
- **继承者**：**[[前秦]]**（376年灭前凉）
- **盟友**：**[[成汉]]（[[张骏]]曾与之联络以抗中原）**（见 [[张骏]] 条）
- **主要对手**：[[后赵]]、[[前秦]]
- **所奉之朝**：**西晋 → 东晋** —— **名义上长期奉其正朔**（见 [[张轨]]、[[张寔]] 条）
- **后世传承**：**前凉亡后其地入[[前秦]]**；**[[前秦]]崩解后，**河西分裂为[[后凉]]、[[南凉]]、[[北凉]]、[[西凉]]**（见 [[后凉]]、[[沮渠蒙逊]]、[[秃发傉檀]]、[[李暠]] 条）
- **文化传承**：**前凉保存的中原学术经[[北魏]]东传** —— **为北朝与隋唐的礼乐制度提供了人才与典籍**（见 [[张轨]]、[[张骏]] 条）

## ⚖️ 历史评价

**十六国中少有的长期安定、保存中原文化的政权 —— 这是前凉最核心的历史地位**。

**其最特殊之处在于「**晋臣**」的身份**：**[[张轨]]以**西晋凉州刺史**起家**；**子孙世袭其职，**始终奉晋正朔**（**不改元、不称帝**）—— **在十六国诸雄纷纷自立称帝的时代，这是极为罕见的立场**（见 `🏛️政治制度`）。

**其历史贡献在于「**保存中原文化**」**：**[[张轨]]「**劝课农桑、兴办学校、礼遇士人**」** —— **311 年永嘉之乱后「**避难来者日月相继**」，**河西成为乱世中保存中原文化的避难所**；**前凉近八十年的安定，**保存了中原的学术与典籍**（见 [[张轨]] 条）。
- **更深远的影响**：**439 年[[北魏]]灭[[北凉]]后，**河西学者东迁，**反哺北朝的礼乐制度** —— **陈寅恪论隋唐制度渊源，特别重视河西一脉**（见 [[张轨]] 条）

**其衰亡在于「**宗室内争**」**：**[[张重华]]卒后（353年）内乱频起**，**君主更替频繁**；**376 年为[[前秦]]所灭**（见 [[张重华]]、[[张天锡]] 条）。**故史家论前凉，常谓其「**其兴也以保境安民，其亡也以宗室内争**」。**

## 🔀 争议与不同观点

> [!quote] ⚖️ 争议说明
> - **争议点一：立国时间**——**以[[张轨]]刺凉（301）还是[[张寔]]继掌（314／320）为起点，说法不一**。**本库采用「**[[张轨]]为奠基者、[[张寔]]为实际立国之始**」的处理**（见 [[张轨]]、[[张寔]] 条）
> - **争议点二：[[张轨]]忠晋是否真诚**——**史载其自请凉州时已有「**阴图保据河西之志**」。**一方视为忠臣**；**一方认为其勤王含自保成分**。**两说并存**（见 [[张轨]] 条）
> - **争议点三：[[张骏]]「**假凉王**」的性质**——**一方视为前凉正式立国的标志**；**一方认为其形式上仍奉晋正朔，「**凉王**」只是「**假**」（代理）之称** —— **前凉是否算「**称王**」学界有不同处理**（见 [[张骏]] 条）
> - **争议点四：「**前凉**」名称的由来**——**[[张轨]]、[[张寔]]本人从未称凉王**，**「**前凉**」为后世为区别[[后凉]]、[[南凉]]等而追称**（见 [[张轨]] 条）
> - **来源**：《晋书·张轨传》（卷八六）《资治通鉴》卷八四—一〇四、**陈寅恪《隋唐制度渊源略论稿》**
