# 桓温北伐

## ⚔️ 战争概览

桓温北伐是东晋权臣[[桓温]]主导的三次大规模北伐行动，分别发生于**354年、356年和369年**。其主要目标是北伐中原、收复东晋故土，同时扩大[[桓温]]个人及[[荆州]]军事集团的政治影响力。

三次北伐均取得过一定军事成果，但最终未能长期恢复东晋对北方领土的控制。

## 📜 战争背景

东晋建立后，北方大片地区长期处于十六国政权控制之下。

桓温掌握荆州以后，逐渐成为东晋最重要的军事集团首领之一。

与此同时，东晋名将[[殷浩北伐]]失败，使桓温获得了更大的政治空间。

桓温随后通过北伐：

1. 扩大军事威望；

2. 收复部分失地；

3. 建立北伐功绩；

4. 提升自己在朝廷中的政治地位。
